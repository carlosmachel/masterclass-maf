tópico técnicoMiddleware contra prompt injection

  • Um comunicado com uma instrução escondida (comentário HTML) entra na base de conhecimento.

05 · o ataque ao vivo · a defesa

O documento passa pela alfândega.

Security/DocumentShield.cs · AnalystAgent.cs

// AnalystAgent.cs: function-calling middleware
harness.AsBuilder()
    .Use(sp.GetRequiredService<DocumentShield>().InvokeAsync)
    .Build()

public async ValueTask<object?> InvokeAsync(AIAgent agent,
    FunctionInvocationContext context, ... next, CancellationToken ct)
{
    var result = await next(context, ct);            // the tool runs
    if (context.Function.Name != "SearchKnowledgeBase") return result;

    var attacks = await shields.DetectDocumentAttacksAsync(question, texts, ct);
    // an attacked passage becomes a quarantine notice: the model never reads it
    Activity.Current?.AddEvent(new("prompt_shields.attack_detected", ...));
    return passages.Select((p, i) => attacks[i] ? p with { Text = Quarantine } : p);
}

entre a tool e o modelo

O middleware vê o resultado antes do modelo. O ataque não chega ao contexto.

no trace

O evento aparece no span execute_tool do Aspire.

public class RedTeamEval(Suite suite)
{

    [InlineData(Model.Local, false)]     // falls: the regression the eval catches
